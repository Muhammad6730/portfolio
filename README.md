# Muhammad — Portfolio

Single-file portfolio site (HTML + CSS + vanilla JS). Live at https://muhammad.technestnova.com/

## Structure
```
index.html        the whole site
images/
  profile.jpg     profile photo (add this, square, 600x600+)
```

## Replace placeholders
Open `index.html` and search for `REPLACE` (5 spots):

- 3 × "View Project" buttons

Change only the `#` inside `href="#"`.

## Deploy
Upload `index.html` and the `images/` folder to the subdomain root. No build step.

## Automation Lab
`images/projects/*.webp` are the workflow screenshots from the GitHub repos at github.com/Muhammad6730.
To add a new workflow, copy one `<article class="lab-card">` block in `index.html`, change the image, text and repo link.
